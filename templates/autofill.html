What it does

  1. You tap Copy & open Amazon.ca on a client.
  2. On Amazon it fills in that client's email and taps Continue.
  3. On the next page it fills in the 6-digit PIN and stops. You check it, continue, and paste the OTP from here.

The email and PIN are passed over only when you tap the button and are forgotten after 3 minutes.

iPhone (Safari)

  1. Install the free Userscripts app from the App Store. Open it once and pick a folder when it asks where to save scripts.
  2. Open Settings → Apps → Safari → Extensions → Userscripts, turn it on, and allow it on All Websites.
  3. In Safari, open the script link below. Tap the Aa (or puzzle) icon in the address bar → Userscripts → Install.
  4. Use OTP Desk in Safari from now on. Chrome on iPhone can't run scripts.

Computer (Chrome)

  1. Install the free Tampermonkey extension from the Chrome Web Store.
  2. Go to chrome://extensions → Tampermonkey → Details and turn on Allow User Scripts (newer Chrome versions need this).
  3. Open the script link below. Tampermonkey shows an install page → click Install.
